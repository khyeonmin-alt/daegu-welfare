 사용 안내 (README)
================================================================

 파일      : 행복이어봄_대구연계.html
 개발      : 대구광역시 복지정책과 김현민 (사회 7급)
 출품      : 2026 대구광역시 AI 행정혁신 경진대회 (업무 프로세스 혁신형)
 기준 연도 : 2026년 지침


----------------------------------------------------------------
1. 한눈에 보기
----------------------------------------------------------------

 상담 메모나 녹음을 넣으면 AI가 성명·가구원·소득·재산 같은 항목을
 원문 근거와 함께 뽑아내고, 프로그램이 2026년 지침대로 계산해
 아래 결과를 한 번에 만들어 줍니다.

  - 초기상담 사정표, 4대 급여 모의판정(생계·긴급복지·차상위·기초연금)
  - 행복e음 초기상담이력 표준 서식 일지 (복사해 붙여넣기)
  - 가구별 맞춤 구비서류 안내문 (민원인 출력용)
  - 유관기관 지원사업 및 대구시 연계 지원사업 안내
    (달구벌 희망급여, 저소득 가구 입원 간병비 지원)
  - 위기상담 시 긴급복지 우선 검토 알림, 신고의무 공문(안)

 설계 원칙 : "AI는 읽기만 하고, 계산과 판정은 프로그램이 지침대로 한다."
   · AI는 상담 원문에서 사실만 추출하며, 모든 값에 원문 근거를 붙입니다.
   · 원문에 없는 금액·근거는 자동으로 폐기됩니다.
   · 규칙 기반 점검과 결과가 다르면 '확인 필요'로 표시합니다.
   · 모의판정은 담당자 참고용이며, 실제 급여 결정은 기존 절차
     (행복e음 조사·판정)에 따라 담당자가 합니다.


----------------------------------------------------------------
2. 바로 실행하기 (설치 없음)
----------------------------------------------------------------

 1) "행복이어봄_대구연계.html" 파일을 더블클릭합니다.
    크롬(Chrome) 또는 엣지(Edge) 브라우저에서 열립니다.

 2) 1단계 화면 오른쪽 위의 예시 버튼(기초생활 / 차상위 / 긴급복지 /
    기초연금) 중 하나를 누르면 모의 상담 기록이 채워집니다.

 3) "AI 분석 실행" 버튼을 누르면 2단계로 넘어가 결과가 표시됩니다.

 ※ AI 서버가 없어도 동작합니다.
   AI 서버에 연결되지 않으면 자동으로 "규칙 기반 분석"으로 전환되어
   모든 계산·판정·서류 안내가 정상 표시됩니다.
   (화면에 "AI 서버 연결 실패: 규칙 기반으로 분석했습니다" 안내가 뜹니다.)


----------------------------------------------------------------
3. 화면 구성 (4단계)
----------------------------------------------------------------

 [1단계] 상담 기록 입력
   - 상담 메모를 자유롭게 입력하거나 표준 서식 예시를 불러옵니다.
   - "상담 녹음 → 글 변환"으로 휴대폰 녹음 파일(m4a, mp3 등)을
     녹취록으로 바꿀 수 있습니다. (아래 5번 참고)
   - 성명·연령·가구원·소득·주거·재산 등 필수 항목이 빠지면
     알림과 함께 서식 템플릿을 넣어 줍니다.
   - 주민등록번호·전화번호·계좌번호는 AI 처리 전에 자동으로 가립니다.

 [2단계] 전산 검증
   - AI 추출 근거 및 교차검증 표 : 항목마다 원문 구절이 노란색으로
     표시됩니다. '확인 필요' 항목은 표 맨 위에 모입니다.
   - 위기사유가 감지되면 긴급복지 우선 검토 알림이 뜹니다.
   - 초기상담 사정표, 4대 급여 모의판정, 행복e음 일지가 만들어집니다.
     "일지 전문 복사"를 눌러 행복e음에 붙여넣으면 됩니다.
   - 학대·폭력 정황이 있으면 신고의무 공문(안)이 생성됩니다.

 [3단계] 민원인 맞춤 서류·연계 안내
   - 구비서류를 "기본 서류"와 "이 가구 맞춤 서류"로 나누고,
     맞춤 서류마다 해당 사유를 적어 줍니다. "즉시 출력"으로 인쇄합니다.
   - 상담 내용에 맞는 유관기관 지원사업(8개 기관)과
     대구시 연계 지원사업을 소득·재산 기준과 함께 안내합니다.

 [4단계] 소득인정액 시뮬레이터
   - 소득평가액 → 재산의 소득환산액 → 소득인정액 산출식을 공개합니다.
   - 값을 고치면 바로 다시 계산되고, 기준값의 지침 출처가 표시됩니다.

4. AI 연결하기 (선택 사항)
----------------------------------------------------------------

 AI 추출을 쓰려면 PC 또는 기관 내부 서버에 AI 모델이 있어야 합니다.
 상담 내용은 외부 인터넷 서버로 보내지 않고, 설정한 주소로만 전송됩니다.

 [PC에 Ollama로 설치하는 경우 (기본 설정)]
   1) Ollama 설치 : https://ollama.com 에서 Windows용 설치 파일 실행
   2) 모델 내려받기 : 명령 프롬프트(cmd)에서
        ollama pull gemma3:4b
   3) 브라우저 접속 허용 : Windows "사용자 환경 변수"에 아래를 추가
        변수 이름 : OLLAMA_ORIGINS     변수 값 : *
      → 작업표시줄 Ollama 아이콘에서 "Quit Ollama" 후 다시 실행
        (안 되면 PC 재부팅)
   4) 화면 오른쪽 위 "⚙ AI 엔진 설정" → "AI 연결 테스트"로 확인

 [기본 설정값]
   - 서버 주소 : http://localhost:11434/v1  (Ollama)
   - 모델명    : gemma3:4b
   - 응답 제한 : 300초 (일반 사무용 PC의 CPU 처리 기준)

 [다른 서버를 쓰는 경우]
   "AI 엔진 설정"에서 서버 종류만 바꾸면 됩니다.
   - vLLM (기관 서버)  : http://localhost:8000/v1
   - LM Studio (로컬)  : http://localhost:1234/v1
   - 직접 입력        : 행안부 AI 공통기반 등 OpenAI 호환 주소
   모델명만 바꾸면 Gemma, EXAONE, Llama, GPT-OSS 등을 쓸 수 있습니다.

 ※ 설정은 이 PC의 브라우저에만 저장됩니다.


----------------------------------------------------------------
5. 상담 녹음 → 글 변환 (선택 사항)
----------------------------------------------------------------

 - 기본은 "PC 안에서 처리" 방식이며, 녹음이 PC 밖으로 나가지 않습니다.
 - 음성인식 모델 : whisper-small (약 250MB, 권장)
                   whisper-base (약 80MB, 빠름)
                   whisper-large-v3-turbo (약 1GB, 그래픽카드 권장)
 - 처음 한 번은 인터넷으로 모델을 내려받고, 이후에는 브라우저에
   저장된 모델을 사용합니다.
   인터넷이 막힌 업무망에서는 "모델 내려받을 주소"를 기관 내부
   저장소로 바꾸거나, 음성인식 서버 연결 방식을 사용합니다.
 - 녹음은 민원인에게 목적·보관기간을 알리고 동의를 받은 경우에만 하고,
   녹취록 변환 후 원본 음성 파일은 삭제합니다.
   녹음 없이 메모만 입력해도 모든 기능을 쓸 수 있습니다.

6. 시연 예시 (대구 거주 위기가구)
----------------------------------------------------------------

 아래 내용을 1단계 입력창에 붙여넣고 "AI 분석 실행"을 누르세요.

   이름: 김영희 (생년월일 1974.5.3.)
   거주지역: 대구 북구
   가구원: 남편과 둘이 사는 2인 가구
   건강상태: 본인은 특이 질환 없음, 남편은 뇌졸중으로 쓰러져 입원 중
   상담 내용: 간병비가 하루 15만 원이라 감당이 안 된다고 함
   소득: 본인 식당 근로소득 월 120만 원
   주거: 월세 보증금 1000만 원, 월세 30만 원
   금융재산: 통장 잔액 200만 원
   부양의무자: 없음 (자녀 없음, 부모 사망)

 결과 : 생계급여·긴급복지·차상위 모의 선정, 위기사유(중한 질병·부상)
        알림, 재난적 의료비·달구벌 희망급여·입원 간병비 지원 안내,
        생계급여와 희망급여의 중복 여부 주의 안내가 함께 표시됩니다.

7. 반영 기준과 갱신 방법
----------------------------------------------------------------

 [반영 기준 (2026년)]
   - 국민기초생활보장사업 안내 : 선정기준, 근로·사업소득 공제,
     기본재산액, 주거용재산 한도, 재산 소득환산율
   - 긴급지원사업 안내 : 소득·재산·금융재산 기준, 생계지원액
   - 기초연금 사업안내 : 선정기준액, 소득인정액 산정 기준
   - 2026년 대구시 달구벌복지기동대 사업운영 :
     달구벌 희망급여, 저소득 가구 입원 간병비 지원

 [매년 지침이 바뀔 때]
   기준값은 프로그램 안의 기준표 한 곳에 모아 두었습니다.
   HTML 파일을 메모장 등으로 열어 아래 이름을 찾아 값만 고치면
   전체 판정에 반영됩니다.
   - POLICY_2026     : 국민기초·긴급지원·기초연금 기준값
   - POLICY_SOURCES  : 기준값별 출처와 확인 상태 (4단계 화면에 표시)
   - DAEGU_LOCAL     : 대구시 연계사업 기준값 (기준 중위소득 100%,
                       희망급여 재산·금융재산 기준, 지원금액 범위)
   - LOCAL_RULES     : 대구시 연계사업 안내 문구·감지 조건
   - AGENCY_RULES    : 유관기관 지원사업 안내 문구·감지 조건

8. 알아 둘 점 (현재 한계)
----------------------------------------------------------------

 - 모의판정은 참고용입니다. 실제 급여 결정은 행복e음 공적자료 조사와
   담당자 판단으로 합니다.
 - 부양의무자 기준과 자동차 재산은 모의계산에 넣지 않습니다.
   (담당자가 별도 확인)
 - 판정 대상은 생계급여·긴급복지·차상위·기초연금 4종이며,
   가구원 수는 7인까지 계산합니다.
 - 행복e음과 직접 연결하지 않고, 생성된 일지를 복사해 붙여넣는
   방식입니다. (시스템 연계 없이 바로 도입 가능)
 - 대구시 연계사업의 구·군별 지원금액, 기관별 세부요건과 예산 소진
   여부는 담당자가 확인해야 합니다.
 - 개발·시연에는 실제 민원인 자료를 쓰지 않고 모의 상담자료만
   사용했습니다.
